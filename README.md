# CISSA-X-GMC-GameJam-Submission

## APE-X 
Ape-X is a 2d platformer/puzzle game made with 3 days, it was made in collaboration with Jasob Abeywickrema, Matt Cheung and Hugo Zubroski
The game is relativley short and was made with zero knowledge about the entry, I only had 48 hrs to contribute and focussed on platformer physics, enemy AI, boss AI, patterns and behavior as well as all ingame asset creation and animation, there are several limitations as far polish is concerned a comes together for a fun expirence that helped to broaden my horizons to team collaboration in stressful conditions. There are many improvements that could still be made but serves as a valubable lesson as far as scope managment when considering projects in general.

Note LEVEL 4 is my largest conttribution soley devleoped by myself.
